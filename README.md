## `05 / HOW I APPROACH BUILDING`

- **Understand the problem** before deciding what to build.
- **Build iteratively** and refine the product as requirements become clearer.
- **Care about usability** as well as implementation.
- **Learn by shipping** projects, debugging issues, and working with existing code.
- **Respect collaboration** by distinguishing team projects from individual work.
